Indicazioni generali (Gattullo e Giovannini, 1989) e loro giustificazione:

| Avvertenza | Perché |
|---|---|
| Linguaggio non inutilmente complicato, adeguato ai destinatari | altrimenti si misurano anche le abilità linguistiche |
| Stimoli brevi ed essenziali | meno tempo, meno stanchezza |
| Niente tranelli | si misurerebbe l'abilità di evitare tranelli |
| Niente domande banali | si misurerebbero conoscenze inutili |
| Niente domande risolvibili con buon senso o cultura generale | si misurerebbero quelli |
| Risposte errate né ingenue né raffinate | si misurerebbero acquisizioni estranee agli obiettivi |
| Citare l'autore se si riportano sue affermazioni | altrimenti non si può giudicarle vere o false |
| Posizione delle risposte esatte non regolare | qualcuno potrebbe scoprirla |
| Non usare frasi copiate dai libri di studio | si premierebbe la memorizzazione |
| Domande indipendenti | i collegamenti facilitano chi li scopre |

Tutte queste regole servono, direttamente o indirettamente, alla [[Validità]]: eliminare ciò che fa variare il punteggio per ragioni diverse dall'abilità che si vuole misurare.
