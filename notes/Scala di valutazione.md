Le scale di valutazione (*rating scales*) rilevano l'**intensità o la frequenza** di un comportamento, oppure esprimono un giudizio su intenzioni, opinioni, atteggiamenti dei soggetti osservati.

L'osservatore indica il proprio grado di accordo o il proprio giudizio per una serie di proposizioni, con un numero, un aggettivo o una descrizione.

| | per niente | poco | abbastanza | molto | moltissimo |
|---|---|---|---|---|---|
| Sorveglia l'andamento del lavoro | | | | | |
| Regola il lavoro di gruppo | | | | | |
| Cura l'uso del tempo | | | | | |

**Rischi tipici**: effetto alone (un giudizio generale contamina i singoli item), tendenza centrale, indulgenza o severità sistematica del valutatore.

Collegamenti: [[Strumenti di osservazione aperti e chiusi]], [[Scala Likert]], [[Scala ordinale]].
