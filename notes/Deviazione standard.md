La deviazione standard (scarto quadratico medio) indica **quanto mediamente ciascun valore si discosta dalla media**.

**Formula**: σ = √( Σ (Xᵢ − M)² / N )

1. si calcola lo scarto di ogni valore dalla media;
2. si elevano al quadrato gli scarti e si sommano;
3. si divide per N;
4. si estrae la radice quadrata.

**Esempio**: 1, 4, 5, 7, 10. Media 5,4. Scarti al quadrato: 19,36 + 1,96 + 0,16 + 2,56 + 21,16 = 45,2. 45,2 / 5 = 9,04 (varianza). √9,04 ≈ 3,0.

Quando si stima la deviazione standard di una popolazione a partire da un campione si divide per N − 1 (deviazione standard campionaria, quella calcolata di default da molti software).
